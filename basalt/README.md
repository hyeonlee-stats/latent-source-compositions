# Chemical compositions of experimental basaltic melts

This folder analyzes the experimental basaltic melts data that are composed by Yang et al. 2019 Using major element logratios to recognize compositional patterns of basalt: Implications for source lithological and compositional heterogeneities.

## Source
Original datasets are publicly available at [1] as Table S1 and Table S2.

## Preprocessing
Datasets in this folder are reformatted versions of the original data.

Table S1 was pre-process into `yang 2019 basalt source labels.csv` by excluding annotating rows and unnecessary columns.

Table S2 was pre-process into `yang 2019 basalt source labels.csv` by adding 'Type' variable based on the information provided by Table S2.
