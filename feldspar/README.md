# Feldspar mineral compositions

This folder analyzes the feldspar mineral compositions dataset filtered from the GEOROC Compilation: Minerals precompiled dataset V10.

## Source

Original datasets are publicly available at <https://doi.org/10.25625/SGFTFN>.

## Preprocessing

`data/alkali.feldspars.xls` and `data/plagioclase.xls` are filtered versions of the original feldspar data.

These files were processed and combined into `data/feldspar.csv`.
